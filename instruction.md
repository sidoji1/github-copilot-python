# GitHub Copilot Instructions

## Project Goal

Refactor the legacy Flask Sudoku application into a clean, modern, modular application while preserving functionality and adding new features.

## Coding Standards

- Use Python 3.13
- Follow PEP 8
- Write clean, modular, and reusable code.
- Use descriptive variable and function names.
- Keep functions short and focused.
- Add docstrings where appropriate.
- Avoid duplicate code.
- Handle errors gracefully.

## Testing

- Use pytest.
- Ensure tests pass before and after every change.

## Frontend

- Build a responsive interface.
- Support both light and dark mode.
